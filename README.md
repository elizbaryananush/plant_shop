# Plant Shop

A full-stack e-commerce web application for browsing and purchasing plants. Built using the MERN stack with Redux for state management.

---

## 🚀 Features

* **User Authentication:** Secure user registration, login, and account management.
* **Product Catalog:** Browse a variety of indoor and outdoor plants.
* **Shopping Cart & Checkout:** Add items to the basket, adjust quantities, and manage orders.
* **State Management:** Seamless global state handling for user sessions and cart items via Redux.

---

## 🛠️ Tech Stack

* **Frontend:** React, Redux
* **Backend:** Node.js, Express
* **Database:** MongoDB
